# AI Video Assistant with RAG

An advanced AI-powered video assistant built using Python, leveraging Retrieval-Augmented Generation (RAG) to transcribe videos, summarize content, and answer queries directly from video data.

## 🚀 Features
- Automated video transcription and analysis using Whisper and LLMs.
- Retrieval-Augmented Generation (RAG) for accurate, context-aware Q&A from video content.
- Clean and interactive user interface for seamless export of notes and summaries.

## 🛠️ Tech Stack
- **Python, LangChain, RAG, Whisper, Streamlit/APIs**
